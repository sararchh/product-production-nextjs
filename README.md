# Sistema de Gestão - Next.js + SQLite

Sistema de gestão de produtos e produção desenvolvido com Next.js, React e SQLite.

## Tecnologias

- Next.js 15
- React 19
- TypeScript
- SQLite3
- Tailwind CSS
- React Query
- React Hook Form
- Zod

## Instalação

```bash
yarn install
yarn migrate
yarn dev
```

## Comandos

- `yarn dev` - Servidor de desenvolvimento
- `yarn build` - Build de produção
- `yarn start` - Servidor de produção
- `yarn migrate` - Migração do banco de dados
- `yarn lint` - Verificação de código

## Banco de Dados

SQLite com tabelas:
- `products` - Produtos
- `productions` - Produções

Arquivo: `database.sqlite`
